# Campus Lost and Found System

## Overview
The Campus Lost and Found System is a Java-based application designed to help students report and locate misplaced belongings within their college campus.

The system provides a centralized platform where users can report lost items, register found items, and search for belongings using relevant information. It aims to simplify the process of recovering lost items within an educational institution.

## Features
- Report lost belongings.
- Register found items.
- Search for lost and found items.
- View item descriptions and related details.
- Maintain organized item records.
- Simple and user-friendly interface.

## Technologies Used
